## AP-0011: AP-0009 (retry): Make clarify and cancel Temporal updates with validators (answerQuestion and cancelRequest), so a change that can't be made gives 409 instead of a 204 that is silently dropped

This is design review 0005, proposal 3, retried at the backlog's request. Clarify and cancel are signals today. RequestController checks the request's state first (requireNotFinished, RequestController.java:347) and then sends the signal. A request that finishes between those two calls still gets a 204 for a change that is silently dropped. A cancel during PROVISIONING also returns 204 and does nothing. confirmSpec already does this properly: it is an update with a validator, and ApiErrorHandler.updateRefused maps a refused update to 409.

Plan:
(1) Add two @UpdateMethods to IntentWorkflow, each with an @UpdateValidatorMethod. answerQuestion(String answer) is refused unless the state is AWAITING_CLARIFICATION and the request isn't cancelled. cancelRequest() is refused once the request is already cancelled, once the build has started (PROVISIONING, which includes multi-VM builds), or once the request has finished. It stays accepted in STARTING, INTERPRETING, AWAITING_CLARIFICATION and AWAITING_CONFIRMATION, as today: a cancel during INTERPRETING takes effect at the next wait. Each handler sets the same fields as the existing signal (answers.add / cancelled = true), so the workflow's sequence of commands doesn't change. Keep the old clarify and cancel @SignalMethods unchanged, so running workflows and the recorded intent-v1-*.json histories still replay.
(2) RequestController.clarify and cancel call the new updates and no longer call requireNotFinished first. A refused update becomes 409 through the existing ApiErrorHandler.updateRefused. finishedOr404 stays for closed workflows, so unknown IDs still give 404 and closed ones give 409.
(3) Update the @ApiResponse / @Operation text, docs/API.md and the regenerated docs/openapi.json and docs/openapi.yaml.
(4) Add unit tests for both validators, plus a replay round trip.
